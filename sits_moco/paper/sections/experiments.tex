\section{Experiments}
\label{sec:experiments}

\subsection{Proposed model}
The proposed model is MSTNet: one STNet trunk for Sentinel-2, one for daily Xavier climate (precipitation, ETo, Rs, Tmax, and Tmin), and late fusion of MapBiomas Solo properties in the decoder.
Each trunk uses one Transformer layer with $d_{\mathrm{model}}=128$, two attention heads, $d_{\mathrm{inner}}=256$, and dropout $0.4$.
Reported metrics apply the selected weights pixel by pixel and average the scores to municipalities (Section~\ref{sec:pixel-formulation}). We select the epoch with the highest validation $R^2$ of those municipal aggregates; that epoch is 12.
The selected checkpoint is evaluated once on the held-out test municipalities.

\subsection{Spectral-only reference}
For context, we report results from a separate grid search using spectral inputs only:
$d_{\mathrm{model}}\in\{64,96,128\}$, number of heads $\in\{4,8\}$, $d_{\mathrm{inner}}\in\{64,128\}$, and dropout $\in\{0.3,0.4\}$, with a single Transformer layer.
Twenty-four configurations completed successfully.
The best spectral-only model ($d_{\mathrm{model}}=96$, eight heads, $d_{\mathrm{inner}}=64$, dropout $0.3$) is reported as a reference. It differs from MSTNet in both inputs and architecture, so this is not a controlled estimate of what climate or soil add on their own.

\subsection{Evaluation protocol}
Held-out evaluation compares municipal predictions with PAM labels on the 2021 validation and test municipalities.
We also report learning curves, predicted-versus-observed municipal scatterplots for harvest years 2020--2024, and a municipal error map for the 2021 holdout.

\subsection{Ablations}
We report two auxiliary comparisons: the spectral-only reference above, and a temporal-pooling comparison that swaps NDVI-weighted pooling for mean pooling over valid timesteps in the spectral-only architecture. These are descriptive checks, not controlled multimodal ablations.
